How It Works

🔍

Feature Extraction

18 URL features are extracted: IP detection, HTTPS status, domain length, suspicious keywords, entropy, punycode, and more.

🤖

ML Classification

A Random Forest classifier trained on phishing and legitimate URL patterns evaluates the extracted features.

📊

Risk Scoring

The model outputs a probability score (0-100%) with a full breakdown of which features triggered the detection.
