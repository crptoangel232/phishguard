How It Works

🔍

Phishing Detection

18 URL features extracted and classified by a Random Forest ML model trained on phishing patterns.

Port Scanning

Scans 60+ common ports using Python sockets with concurrent threading. Detects services and captures banners.

Vulnerability Assessment

Each open port is evaluated against known vulnerability patterns with risk-level classification and remediation guidance.
